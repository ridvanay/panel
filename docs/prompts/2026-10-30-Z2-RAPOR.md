## Canlıya alma ve içe aktarma (G/L/T yöntemi)

1. **Kod ve migration:**
   1. dalı master'a al ve `git pull`;
   2. migration: compose ağında tek kullanımlık `node:20-alpine` (+openssl) konteynerinde `npx prisma migrate deploy` (`20261109090000_blog_category_translations`);
   3. `docker compose up -d --build --no-deps backend frontend`.
2. **Parti dosyasını ve script'i konteynere kopyala:**
   ```bash
   docker compose cp backend/scripts/import-blog-posts.ts backend:/app/scripts/
   docker compose cp imports/blog/batch-01.json backend:/tmp/batch-01.json
   ```
3. **Kuru çalıştırma** (hiçbir şey yazmaz; "VARSAYILAN DİL EN DEĞİL" uyarısı çıkmamalı, 0 hata beklenir):
   ```bash
   docker compose exec backend npx tsx scripts/import-blog-posts.ts --file=/tmp/batch-01.json
   ```
4. **Gerçek yazım:**
   ```bash
   docker compose exec backend npx tsx scripts/import-blog-posts.ts --file=/tmp/batch-01.json --confirm=import-blog --operator=<ad>
   ```
   Çıktı yedek dosyasının yolunu ve geri alma komutunu basar. Yedeği gerekirse `docker compose cp` ile dışarı alın.
