## Sırpça kodu: `sr-latn` (gerekçe)

- `Intl`'in Sırpça varsayılanı **Kiril**dir: `new Intl.DateTimeFormat("sr")` → "среда, 28. октобар 2026". `sr` kodunu "Latin zorunlu" olarak kullanmak, `Intl`'e giden her çağrıda ayrı bir eşleme gerektirir; unutulan tek bir çağrı Kiril metin gösterir.
- `sr-latn` kodu ise `Intl`'e ham hâliyle bile gitse Latin çıktı verir ("sreda, 28. oktobar 2026", "Nemačka", "turski"). Yani "hiçbir yerde Kiril yok" kuralının en güvenli garantisi.
- Tireli kod için gereken değişiklik sınırlı çıktı: iki harf varsayımı tek bir desende (`locale-code.ts`) toplandı.
- Eşlemeler: URL öneki `/sr-latn`, hreflang `sr-Latn`, Intl `sr-Latn-RS`, bayrak `rs`, yerel ad "Srpski".
- Tarayıcı dili `sr`, `sr-RS`, `sr-Cyrl`, `sr-Latn-RS` → `sr-latn` (Kiril sürüm olmadığı için; yalnızca `sr-latn` açıksa).
- Doktorun konuştuğu dil (`DOCTOR_LANGUAGE_OPTIONS`) ISO 639-1 `sr` olarak kalır; adı her zaman ziyaretçinin Intl diliyle (`sr-Latn-RS` vb.) yazılır.

## Canlıya alma sırası

Sunucuda, depo kökünde (`/var/www/tele-health`). Scriptler backend imajına gömülü değil (Paket L'deki gibi). Her script adımından önce bir kez kopyalanır:
```bash
docker compose cp backend/scripts backend:/app/scripts
docker compose cp backend/src backend:/app/src
docker compose cp backend/tsconfig.json backend:/app/tsconfig.json
```

**1. Backend** — `docker compose up -d --build --no-deps backend`

**2. Frontend** — `docker compose up -d --build --no-deps frontend`

**3. `add-site-locales` (diller kapalı)** — önce yukarıdaki `docker compose cp` adımı
```bash
docker compose exec -T backend sh -c "cd /app && npx -y tsx@4.23.1 scripts/add-site-locales.ts"
# Kuru çalışmada yalnızca ro (6), fr (7), sr-latn (8) "eklenecek" görünmeli.
docker compose exec -T backend sh -c "cd /app && npx -y tsx@4.23.1 scripts/add-site-locales.ts --confirm=add-locales --operator='Ad Soyad'"
```

**4. Export (yalnızca yeni üç dilin yuvaları)**
```bash
docker compose exec -T backend sh -c "cd /app && npx -y tsx@4.23.1 scripts/export-translatable-content.ts --locales=ro,fr,sr-latn --out=storage/translations/export-ro-fr-sr.json"
docker compose cp backend:/app/storage/translations/export-ro-fr-sr.json ./translations-export-ro-fr-sr.json
```

**5. Çeviri** — ayrı oturumda yalnızca `translations.ro|fr|sr-latn` alanları doldurulur (Sırpça yalnızca Latin alfabesi). Yapı, bağlantı ve URL değişmez; `instructions` alanındaki kurallar geçerli.
