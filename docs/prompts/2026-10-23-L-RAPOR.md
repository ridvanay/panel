### Sertifika PDF'i
- Script, PDF'i projenin medya servisiyle (`STORAGE_DRIVER` ne ise) **public medya** olarak yüklüyor ve `Media` kaydı oluşturuyor.
- CV kalemine `mediaId` ve `url` yazılıyor. Profilde CV ve Uzmanlık sekmelerinde "Sertifikayı görüntüle / View certificate" bağlantısı çıkıyor ve yeni sekmede açılıyor (`rel="noopener noreferrer"`).
- Tekrar çalıştırmada aynı PDF yeniden yüklenmiyor; mevcut kayıt (dosya adı + boyut + tür + sabit alt metin) kullanılıyor.
- **Güvenlik:** `url` istemciden alınmıyor. Admin oluşturma/güncelleme ve doktor portalı yazma yollarında `mediaId`'den `Media.url` türetiliyor. Yalnızca PDF ya da görsel kabul ediliyor. `url`, `mediaId` olmadan, sertifika/ödül dışı bir kalemde ya da `..` içeriyorsa reddediliyor. Admin CV editörü kaydederken bu alanları korur.
- **Elle kontrol (KVKK incelemesi):** PDF yüklenmeden önce açılıp kişisel iletişim bilgisi ve metadata (Author/XMP) taşıyıp taşımadığına bakılmalı. Kod yalnızca `%PDF-` başlığını kontrol ediyor.
- `--restore` profil alanlarını geri alır ama yüklenen PDF'i ve `Media` kaydını silmez. Gerekirse medya kütüphanesinden silinebilir.

### Çalışma şekli
Script: `backend/scripts/update-vahit-mutlu-profile.ts`, mantık `src/lib/doctor-cv-import.ts`.
- Varsayılan **kuru çalışma**. Mevcut ve yeni kalem sayılarını (cv/publications), bio/about uzunluklarını, yüklenecek dosyayı ve eklenmeyen kalemleri listeler.
- `--confirm=update-vahit --operator=...` verilince sırasıyla:
  1. `storage/doctor-backups/vahit-mutlu-<zaman>.json` yedeği yazılır (0600).
  2. Yazma tek transaction'da yapılır. Plan ile yazma arasında kayıt değiştiyse işlem geri alınır.
  3. Audit log'a `doctor.profile.imported` düşer.
  4. `doctors` önbellek etiketi yenilenir.
- `--restore=<yedek> --confirm=restore-vahit --operator=...` yedekteki unvan, bio, about, cv, yayın, sosyal, uzmanlık ve ek uzmanlıkları geri yazar. Yalnızca `vahit-mutlu` yedeği kabul edilir ve yedek şemadan geçirilir.
- `--dir=<klasör>` ile kaynak klasör verilebilir.
- Değişmeyen kurallar: doktor oluşturmaz; `id`, `slug`, `userId`, `fullName`, `avatarMediaId`, `subSpecialty`'ye dokunmaz; WhatsApp eklemez.
- **Dil:** içerik İngilizce. TR ve diğer diller A5'teki `translations` ve import akışıyla gelir.

  - randevu sihirbazı, kimlik ve belge adımları, takvim, hizmet özeti
  - hasta ve doktor portalı tabloları (ödemeler, kazançlar, randevular, fatura)
  - katalog filtreleri, sayfalama, ürün kartı ve sayfası, sepet, checkout, iletişim formu, hesabım sayfaları
- **Bilinçli olarak fiziksel bırakılanlar:**

## Canlıya alma sırası
Komutlar sunucuda repo kökünden çalıştırılır. Scriptler backend imajına gömülü değil; Paket G/J'deki gibi `docker compose cp` + `npx -y tsx@4.23.1` ile çalıştırılır.

**1. Yedek**
```bash
docker compose exec -T db pg_dump -U postgres -d saas_prod -Fc -f /tmp/backup_$(date +%Y%m%d%H%M%S).dump
```

**2. Migration** (deploy'dan ÖNCE; prod imajında prisma CLI yok, bilinen yöntem):
```bash
DB_URL=$(docker compose exec -T backend printenv DATABASE_URL | tr -d '\r')
NET=$(docker inspect -f '{{range $k,$v := .NetworkSettings.Networks}}{{$k}}{{end}}' $(docker compose ps -q db))
docker run --rm --network "$NET" -v "$PWD/backend/prisma:/app/prisma" -w /app -e DATABASE_URL="$DB_URL" \
  node:20-alpine sh -c "apk add --no-cache openssl >/dev/null && npx --yes prisma@5.22.0 migrate deploy"
```

**3. Backend**
```bash
docker compose up -d --build --no-deps backend
```

**4. Frontend**
```bash
docker compose up -d --build --no-deps frontend
```

**5. `update-vahit-mutlu-profile`** — önce kuru çalışma, sonra gerçek çalışma
```bash
# Kaynak dosyalar (CV + sertifika PDF'i) sunucuya ayrıca kopyalanır; repoda yoklar.
docker compose cp backend/scripts backend:/app/scripts
docker compose cp backend/src backend:/app/src
docker compose cp backend/tsconfig.json backend:/app/tsconfig.json
docker compose exec -T backend mkdir -p /app/imports
docker compose cp imports/vahit-mutlu backend:/app/imports/vahit-mutlu
# Kuru çalışma — sayıları ve "gizli bilgi taraması: temiz" satırını kontrol edin.
docker compose exec -T backend sh -c "cd /app && npx -y tsx@4.23.1 scripts/update-vahit-mutlu-profile.ts --dir=imports/vahit-mutlu"
# Gerçek çalışma
docker compose exec -T backend sh -c "cd /app && npx -y tsx@4.23.1 scripts/update-vahit-mutlu-profile.ts --dir=imports/vahit-mutlu --confirm=update-vahit --operator='Ad Soyad'"
# Kişisel bilgi içeren kaynakları konteynerden silin; yedeği dışarı alın.
docker compose exec -T backend rm -rf /app/imports
docker compose cp backend:/app/storage/doctor-backups ./doctor-backups-$(date +%Y%m%d)
```
