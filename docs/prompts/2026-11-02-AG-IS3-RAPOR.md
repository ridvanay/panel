## 6. Canlıya alma — adım adım (kopyalanabilir)

Bu dal yeni migration **getirmez**. AG migration'ı `20261115090000_external_meetings` AI İş 3 dalıyla birlikte gelir. AJ ve AI İş 3 canlıdaysa yalnızca yeniden derleme yeterlidir; değilse aşağıdaki migration adımı hepsini uygular.

```bash
# 0) Yerelde (siz): dalları sırayla birleştirip gönderin
git checkout master
git merge --no-ff feat/aj-fixes-nov02
git merge --no-ff feat/ai3-coordinator-booking-nov03
git merge --no-ff feat/ag-meetings-rest-nov03
git push
# Sunucuda:
git pull

# 1) Değişkenler
DB_URL=$(docker compose exec -T backend printenv DATABASE_URL | tr -d '\r')
NET=$(docker inspect -f '{{range $k,$v := .NetworkSettings.Networks}}{{$k}}{{end}}' $(docker compose ps -q db))

# 2) Migration (yalnızca ekleme; bekleyen hepsi: AJ contact channel, AG external_meetings, AI3 service_consultations)
docker run --rm --network "$NET" -v "$PWD/backend/prisma:/app/prisma" -w /app -e DATABASE_URL="$DB_URL" \
  node:20-alpine sh -c "apk add --no-cache openssl >/dev/null && npx --yes prisma@5.22.0 migrate deploy"

# 3) Uygulamayı yeniden kur (compose, Nginx, LiveKit ayarı DEĞİŞMEZ)
docker compose up -d --build --no-deps backend frontend

# 4) Kontroller
docker compose exec -T backend printenv LIVEKIT_INTERNAL_URL     # boş OLMAMALI (B8)
docker compose logs --tail=100 backend | grep -i -E "meeting|error"
```

**Geri alma:** genel harici toplantı özelliğini kapatmak için `backend/src/lib/feature-flags.ts` ve `frontend/src/lib/feature-flags.ts` içinde `EXTERNAL_MEETINGS_ENABLED = false` yapıp yeniden derleyin. Hizmet görüşmeleri (AI3) bundan etkilenmez.

## 7. Panelden yapılacaklar

1. **Admin → Kullanıcılar:** toplantı açacak personelin satırında "Harici toplantı oluşturabilir" anahtarını açın (onay penceresi çıkar). Adminler her zaman yetkilidir. Yetki geri alınınca kişinin gelecekteki genel toplantıları iptal olur.
2. Ev sahibi hesaplarında **iki adımlı doğrulamayı** açın. Zorunlu değil ama önerilir; sayfada hatırlatma çıkar.
3. **Toplantılar → Yeni toplantı:**
   - **Başlığa hasta adı yazmayın**, misafirler görür. Not alanını yalnızca ev sahibi görür.
   - Katılımcı sınırı varsayılan 4'tür (ev sahibi dahil, en çok 8).
4. **Bağlantı kartı:** bağlantıyı kopyalayın ya da e-postayla gönderin. Kart kapanınca bağlantı bir daha gösterilmez. Kaybolursa "Yeni misafir bağlantısı" üretin; eskisi geçersiz olur.
5. Toplantıdan 15 dk önce "Katıl" etkinleşir. Misafirler ev sahibi gelene kadar bekler. "Çıkar" ile çıkarılan misafirin geri girmesini önlemek için yeni bağlantı üretin.
6. **Admin → Toplantılar → Tüm toplantılar:** başkalarının toplantısını iptal edebilirsiniz, katılamazsınız. "Service consultation · SVC-…" rozetli satırlar Hizmet Masası'ndan yönetilir.
