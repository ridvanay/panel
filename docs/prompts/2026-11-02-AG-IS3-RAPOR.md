## 4. Dikkat: AJ-5 ile etkileşim

AJ-5 (`be45326`) `doktor.` alt alan adını ve ziyaretçi tarafında `/doctor/**`'u ana siteye 301 yönlendiriyor (`DOCTOR_PORTAL_ENABLED` ile geri açılır). Bu nedenle S1'deki `/{lang}/doctor/meetings` ekranı, doktor portalı kapalıyken **erişilemez olur**. Varsayım: harici toplantılar şimdilik **yalnızca admin panelinden** (`/admin/meetings`) yönetilir; doktor portalı ekranı bayrak açılınca devreye girer. Misafir sayfaları (`/{lang}/meet/join`, `/{lang}/meet/{id}`) ana sitede olduğu için etkilenmez.

## 5. Canlıya alma (AG İş 3 TAMAMLANDIĞINDA — şimdi çalıştırmayın)

```bash
# 0) Sunucuda, depo kökünde
git fetch && git checkout master && git pull

# 1) Değişkenler
DB_URL=$(docker compose exec -T backend printenv DATABASE_URL | tr -d '\r')
NET=$(docker inspect -f '{{range $k,$v := .NetworkSettings.Networks}}{{$k}}{{end}}' $(docker compose ps -q db))

# 2) Migration (yalnızca ekleme: external_meetings tabloları)
docker run --rm --network "$NET" -v "$PWD/backend/prisma:/app/prisma" -w /app -e DATABASE_URL="$DB_URL" \
  node:20-alpine sh -c "apk add --no-cache openssl >/dev/null && npx --yes prisma@5.22.0 migrate deploy"

# 3) Uygulamayı yeniden kur (compose, Nginx, LiveKit ayarı DEĞİŞMEZ)
docker compose up -d --build --no-deps backend frontend

# 4) Duman testi
docker compose logs --tail=100 backend | grep -i -E "meeting|error"
```
