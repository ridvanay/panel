# Paket H — Node 20 → Node 22 yükseltmesi (2026-10-19)

**Hızlı Mod geçerli** (`.claude/CLAUDE.md`). Ajanlar yalnızca inceleyicidir. Testleri ana oturum dosya dosya, sırayla çalıştırır.

## Neden
Canlıda backend açılırken AWS SDK şu uyarıyı veriyor: "versions published after the first week of January 2027 will require node >=22. You are running node v20.20.2." Ocak 2027'den önce Node 22'ye geçmemiz gerekiyor. Bu paket **yalnızca çalışma zamanı sürümünü** değiştirir. Uygulama kodu değişmez.

## Başlangıç
- Branch: `master`'dan (`ed6f8e3`) `chore/node22-oct19` aç.
- Push etme. Commit'leri küçük tut.

## KIRMIZI ÇİZGİ (değişmez)
- `docker-compose.yml`, `docker-compose.dev.yml`, Nginx, tüm `.env` dosyaları
- `livekit` servisi ve imajı, `lib/livekit.ts`, `lib/livekit-egress.ts`, meeting-token, kayıt, `consultation-room.tsx`
- Prisma şeması ve migration'lar (bu pakette migration **olmayacak**)
- Bağımlılık sürümleri: Node 22 ile **zorunlu olarak** uyumsuz çıkan bir paket yoksa `package.json` / `package-lock.json` değişmez. Zorunlu bir değişiklik çıkarsa uygulama, önce gerekçesini rapora yaz ve dur.

## Yapılacaklar
1. **Dockerfile'lar:** `backend/Dockerfile` ve `frontend/Dockerfile` dosyalarında `ARG NODE_VERSION=20-alpine` → `ARG NODE_VERSION=22-alpine`. Başka satıra dokunma.
2. **CI:**
   - `.github/workflows/ci.yml` içinde `NODE_VERSION: "20"` → `"22"`
   - `.github/workflows/deploy.yml` içinde `node-version: "20"` → `"22"`
3. **`@types/node`:** Değiştirme (20 tipleri 22'de sorunsuz çalışır). Sadece raporda belirt.
4. **Native modüller:** `argon2@0.40.3` (şifre hash'leme) ve `sharp@0.34.5` (görseller) Node 22 + Alpine (musl) üzerinde çalışmalı. Doğrulama:
   - Docker varsa:
     ```
     docker build -t th-backend-n22 ./backend
     docker run --rm th-backend-n22 node -e "require('argon2').hash('x').then(h=>require('argon2').verify(h,'x')).then(console.log)"
     ```
     Çıktı `true` olmalı.
   - `docker build -t th-frontend-n22 ./frontend` başarılı olmalı. Google font hatası çıkarsa bir kez tekrar dene; geçicidir.
   - Docker yoksa: Node 22 ile `backend` ve `frontend` içinde `npm ci && npm run build` çalıştır, ardından argon2 kontrolünü yerelde yap. Raporda "Docker ile doğrulanmadı" diye belirt.
5. **Testler:** Node 22 ile backend ve frontend testlerini mevcut düzenle çalıştır (dosya dosya, sırayla). Node 20'de de kırık olan testleri ayrı listele; onları düzeltme.
6. **Belgeler:**
   - `CHANGELOG.md` dosyasına kısa bir giriş ekle.
   - `INFRA.md` içinde Node sürümü geçiyorsa güncelle.
