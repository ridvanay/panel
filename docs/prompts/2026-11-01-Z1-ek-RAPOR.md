**Script'in ekleyeceği yer:**
- **Header:** kök seviyede, `/about` (`/about-us`, `/hakkimizda`) öğesinin önüne; yoksa sona.
- **Footer:** `/about` benzeri bağlantı içeren sütunda o bağlantının önüne; yoksa ilk sütunun sonuna; hiç sütun yoksa footer atlanır.
- Etiket "Health Guides", 9 dil.
- **Idempotent:** `href="/blog"` zaten varsa o menü atlanır.

**Komutlar** (`backend/` dizininde; canlı konteynerde önceki script'ler gibi dosyayı kopyalayıp `docker compose exec` ile):
```bash
npx tsx scripts/add-blog-nav-item.ts                                                  # kuru çalıştırma: neyin nereye ekleneceğini yazar
npx tsx scripts/add-blog-nav-item.ts --confirm=add-blog-nav --operator=<ad>           # yedek (storage/backups/nav-<tarih>.json) + ekleme + audit
npx tsx scripts/add-blog-nav-item.ts --restore=<yedek.json> --confirm=add-blog-nav --operator=<ad>   # geri yükleme
```

**Notlar:**
- Gerçek çalıştırmadan önce kuru çalıştırmanın gösterdiği konumu kontrol edin; canlıdaki "About" href'i farklıysa öğe sona eklenir.
- **Uyarı:** script'ten sonra admin panelinde menüyü, eklenen öğe ekranda görünmeden kaydederseniz bağlantı silinir.
- Geri yükleme, yedekten sonra panelde yapılan menü değişikliklerini de geri alır.
- `storage/backups` konteynerde yazılabilir olmalı, değilse `--backup-dir=<yol>` verin.
